ASIN

MegaLibm

[Mega][megalibm]

|x| <= 0.5:     polynomial to approx
|x| <= 1.:      asin(x) = pi/2 - 2*asin(sqrt((1 - x) / 2))

llvm

[asinf.cpp][llvm]

|x| <  2^-12
|x| <= 0.5:     asin(x) = x * P(x^2)
|x| <= 1.:      asin(x) = y = pi/2 - 2 * asin( sqrt( (1 - x)/2 ) )
|x| >  1.:      NaN

OpenLibm

[e_asin.c][openlibm]

|x| <  0.5:     asin(x) = x + x*x^2*R(x^2)
|x| <  0.975:   asin(x) = pi/2 - 2*(s+s*z*R(z))
|x| <= 1.:      asin(x) = pi/2 - 2*(s+s*z*R(z))
|x| >  1.:      NaN

Glibc

[e_asin.c][glibc]

|x| < 2^-26
|x| < 0.125
|x| < 0.5
|x| < 0.75
|x| < 0.921875
|x| < 0.953125
|x| < 0.96875
|x| < 1
|x| >= 1
