# Frama-C

> Frama-C is a platform dedicated to the analysis of source code written in C.
>
> https://www.frama-c.com/

## Build and Install

- https://www.frama-c.com/html/get-frama-c.html

```sh
# install gtk theme
sudo apt install yaru-theme-icon

# RUN GUI
GDK_BACKEND=x11 GDK_DPI_SCALE=1.2 frama-c-gui
GDK_BACKEND=x11 GDK_DPI_SCALE=1.2 frama-c-gui -machdep gcc_x86_64
```
